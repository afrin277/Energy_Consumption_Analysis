# Energy Consumption Analysis

## Project Overview

Energy Consumption Analysis is a SQL-based data analytics project focused on exploring global energy consumption, energy production, emissions, economic indicators, and population data.

The project uses multiple CSV datasets to organize related information and investigate patterns and relationships across countries and energy-related indicators.

## Project Objectives

- Explore energy consumption and production data.
- Analyze emissions and their relationship with energy-related indicators.
- Examine country-level GDP and population data alongside energy metrics.
- Practice SQL querying, data aggregation, filtering, and analytical reporting.
- Present the analysis in a structured and reproducible project format.

## Tools and Technologies

- **SQL** — Data querying and analysis
- **CSV** — Dataset storage and exchange
- **PowerPoint** — Project presentation
- **Git and GitHub** — Version control and project documentation
