# Energy Consumption Analysis

## Project Overview
This project analyzes energy consumption, production, emissions, GDP, population, and country-level data using SQL.

## Tools Used
- SQL
- CSV datasets
- PowerPoint for project presentation

## Project Files
- `energy_consumption_project1.sql` — SQL queries and analysis
- `consum_3.csv` — Consumption data
- `country_3.csv` — Country information
- `emission_3.csv` — Emissions data
- `gdp_3.csv` — GDP data
- `population_3.csv` — Population data
- `production_3.csv` — Production data
- `Energy_Consumption_Analysis.pptx` — Project presentation

## How to Use
Import the CSV datasets into your SQL database, adjust table names if needed, and execute the queries in the SQL script.
